# Research Operations

A Python-based collection of Operations Research and mathematical optimization problems, focused on applying mathematical methods to solve resource allocation and linear programming problems.

## Overview

This repository documents my work with Operations Research through Python implementations of selected homework and optimization problems. It serves as a collection of solutions and a place to develop my skills in mathematical modeling, computational problem-solving, and optimization.

## Topics Covered

* **Linear Programming:** Formulating objective functions and constraints
* **Optimization Models:** Representing problems mathematically and identifying optimal solutions
* **Simplex Method:** Working with linear programming formulations and solutions
* **Computational Optimization:** Using Python to solve mathematical problems

## Getting Started

### Prerequisites

* Python 3
* NumPy
* SciPy

### Setup

Clone the repository:

```bash
git clone https://github.com/Szagloul/Research_Operations.git
cd Research_Operations
```

Install the required libraries:

```bash
python3 -m pip install numpy scipy
```

Run an individual script:

```bash
python3 HW_2.41.py
```

Replace `HW_2.41.py` with the script you want to run.
